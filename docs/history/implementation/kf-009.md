**Historical measurement method:** 18 trials: six workload/concurrency combinations × three
repetitions, each with 10s warmup and 30s measurement, closed-loop with one outstanding
operation per worker. Shared Apple M4 Pro, 24 GiB, macOS 26.6.2 arm64, APFS; 64–512 MiB
client/server heaps on the same host. All 29,079 acknowledged records were verified outside
timing by exact bytes, key presence, qualified partition, offset, timestamp, and group
progress. These results correspond only to manifest `785879...`, not the corrected source,
and are not capacity or Linux performance claims.
