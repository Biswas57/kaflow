Positive-wait Fetch is registered in bounded `FetchWaiters`. Parked requests retain bounded
metadata only and occupy no read worker, open channel, snapshot, or segment pin. Publication,
deadline, cancellation, and close coalesce activation; ownership and group barriers are
rechecked before a read and delivery. Reservations persist through actual work and response
unwind. Immediate Fetch remains the zero-wait path; waiting never commits or renews a lease.
