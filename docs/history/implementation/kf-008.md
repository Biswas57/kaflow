**Source identity:** initial implementation `d172294e02931242968998cbf37e011fb969cf0b`

KF-008 added retained-start authority, whole closed-segment deletion, pinned reader lifetime,
storage quotas/headroom, overload behavior, and bounded shutdown. Retention defaults off,
does not change group progress, and can permanently remove history from lagging groups.
Catalog V4/checkpoint V2 authorize retention. Active or pinned segments can keep usage above
target. Incomplete shutdown retains the writer and directory ownership until actual I/O ends.
Downgrade after incompatible metadata upgrade is unsupported.
