## Contracts, assumptions and limitations

Retention remains opt-in, whole sealed prefix only; active segment preserved, offsets never
renumbered. Catalog V4/checkpoint V2 authority precedes unlink. No supported downgrade once
upgrade begins; disabling policy does not restore expired history. Lagging progress remains
valid and unchanged. Join/Heartbeat expose bounded range vectors; resets/effective commits
validate current bounds. Previously admitted reads preserve captured bytes under real-lifetime
pins, with membership/lifecycle fencing still required. Stalled pins can cause explicit quota
or segment-count exhaustion; no unbounded growth or early resource release.

Quota includes exact segment/index lengths, pending growth and a conservative metadata/temp
headroom envelope; excludes filesystem allocation blocks/directories/unrelated files/OS caches.
Real ENOSPC still degrades. Timeout outcomes can be unknown. One total monotonic shutdown
budget reports incomplete work while retaining necessary ownership; late cleanup continues.
No safe interruption/replacement of arbitrary blocked filesystem I/O is claimed.

Linux local storage is the durability reference. Local macOS/APFS execution requires honored
file/directory force, atomic same-directory replacement and device flush ordering. CRC detects
damage, not malicious valid-metadata rollback. Process-halt/restart tests are not physical
power-loss proof. No replication, failover, transactions, exactly-once, compaction or measured
performance claim. Full release metrics/examples/Docker/benchmarks remain KF-009.

CI is configured to add the retention smoke and always-uploaded reports. No KF-008 CI run
exists or is claimed: this task does not authorize publication.
