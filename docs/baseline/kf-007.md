## Boundaries and handoff

Only opt-in durable Fetch gains optional waiting. Prototype isolation, Append durability,
durable progress and catalog formats remain unchanged. Linux local storage remains the
reference; macOS process-kill/restart evidence is not physical power-loss proof. File and
directory force, atomic same-directory replacement and honored device flushes remain required.
Catalog V3 still has no supported downgrade to KF-005; no new disk format or migration.

Logical metadata/read/delivery budgets exclude caller allocations and retained values,
transport buffers after handoff, OS cache and total JVM heap. Explicit activation overload
may reject a valid waiter. Bounded fair decisions do not promise success under overload,
exact wall-clock timeout delivery or unmeasured scalability. Waiting never grants continuing
ownership, commits progress or renews leases. Authorized bytes cannot be revoked later.

Publication is authorized; no PR or merge. KF-008 remains unstarted:
retention boundaries, out-of-range semantics, segment pinning, crash-safe deletion, quotas,
overload and bounded shutdown under load.
